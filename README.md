## Features

- **Responsive design** — optimized for desktop, tablet, and mobile
- **Home page** — hero section, amenities grid, photo gallery, animated stats, testimonials slider
- **About page** — hostel story, PAN registration badge, key highlights
- **Contact page** — enquiry form with room booking (Double Seater / Triple Seater), Google Maps embed, phone/email links
- **Django admin** — robust contact management with search, filters, and CSV-ready list view
- **Developer profile** — quick link to the developer's portfolio in nav and footer
- **SEO-friendly** — semantic HTML, meta tags, fast load times
- **Whitenoise** — static file serving for production
- **Environment-based config** — secrets managed via `python-decouple`
