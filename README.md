A modern, responsive website developed for **Peaceful Boys Hostel**, a registered boys' hostel in Tokha-10, Kathmandu, Nepal, serving students and working professionals since 2073 (2016 AD).

This project demonstrates web development skills using Django, Python, HTML, CSS, Bootstrap, and JavaScript.

---

## Live Site

🌐 [peacefulboyshostel.com](https://peacefulboyshostel.com)

---

## Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Home Page** — Hero section, amenities grid, photo gallery, animated statistics, and testimonials slider.
- **About Page** — Hostel introduction, PAN registration badge, and key highlights.
- **Contact Page** — Enquiry form with room selection (Double Seater / Triple Seater), Google Maps integration, and contact links.
- **Django Admin** — Contact management with search, filters, and organized list views.
- **Developer Profile** — Direct links to the developer's portfolio.
- **SEO-Friendly** — Semantic HTML, meta tags, and optimized page structure.
- **WhiteNoise** — Static file serving for production.
- **Environment-Based Configuration** — Sensitive configuration managed using `python-decouple`.
